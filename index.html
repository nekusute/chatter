Firebase の設定が必要です

あと少しで使えるようになります

  1. Firebase コンソールでプロジェクトを作成し、ウェブアプリを登録する
  2. Authentication で メール / パスワード ログインを有効にする
  3. Firestore Database を作成し、README のセキュリティルールを公開する
  4. この HTML 内の firebaseConfig を自分の値に書き換える
// index.html の <script type="module"> 冒頭
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  ...
};

詳しい手順は README.md を参照してください。
